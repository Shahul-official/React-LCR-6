# React API Learning Project 🚀

This project was built as part of my React learning journey.  
It focuses on understanding how to fetch and display API data using **Fetch** and **Axios** along with React Hooks.

---

## 📌 What This Project Covers

- Using **useState** for state management
- Using **useEffect** for side effects
- Fetching data from APIs
- Rendering lists using `.map()`
- Handling API calls using:
  - Fetch with Promises
  - Fetch with async/await
  - Axios with Promises
  - Axios with async/await

---

## 🌐 API Used

Data is fetched from:

https://jsonplaceholder.typicode.com/todos

This is a free fake API used for practice and learning.

---

## 🛠 Tech Stack

- React (Vite)
- JavaScript (ES6+)
- Axios
- HTML & CSS
